# Phase 9 Plan 01: Header-First Shell and Docked Left Pane Contract

## Objective

- **What:** Rebaseline Phase 9 shell architecture to a full-width app header and a docked, resizable left pane model.
- **Why:** The old plan assumed app-level left-sidebar navigation, which conflicts with the approved Lighthouse 2.0 app-header direction.
- **Output:** Stable shell/layout foundation for Phase 9 controls and chart-behavior refinements.

## Scope Boundary

This plan owns shell structure, app header composition, left pane docking/resizing/state precedence, and removal of legacy header block.

This plan does not own detailed top-right control exactness, grid-mode business rules, or chart-card action isolation (covered in 09-02 and 09-03).

## Verification

- **Header contract:** full-width app header above tabs; no legacy breadcrumb/title/subtitle block.
- **App tabs contract:** `Charts` active and `Shape Agents` disabled with tooltip-only behavior.
- **Docked layout contract:** pane never overlays charts; workspace shifts right.
- **Resize contract:** pane width constrained to `320-440`, default `360`.
- **State precedence:** fullscreen force-open; below-1400 collapse; otherwise remembered state.
- **Context contract:** single-active `Equipment/Sensors/Events`.
