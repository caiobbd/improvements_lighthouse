## Verification

Final integrated gate for rebaselined Phase 9:

- **Header/Shell**
  - Full-width main app header exists and is the only row above tabs.
  - Header shows `Lighthouse 2.0`, active `Charts`, disabled `Shape Agents` with tooltip-only behavior.
  - Legacy breadcrumbs/title/subtitle header block is absent.
- **Docked Pane**
  - Pane never overlays charts.
  - Pane resizes in `320-440` bounds with default `360`.
  - Single-active contexts: `Equipment/Sensors/Events`.
  - Full-screen force-open, `<1400` auto-collapse, otherwise remembered state.
  - Collapsed slim icon rail remains visible.
- **Tabs/Controls**
  - Charts tabs and controls are separate rows.
  - Quick ranges and reload/frequency behavior are intact.
  - Grid controls are icon-only `1-col`/`2-col`.
  - Settings gear has exact six actions; metadata/System Info remain hidden.
- **Chart Interaction**
  - `?` does not open `...`.
  - `...` opens only from explicit trigger.
  - Help/menu overlays are mutually exclusive.
