<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sensor row context-menu -> modal input fields | Untrusted operator-entered custom threshold values cross into UI/state and API payloads. |
| frontend API client -> custom alarm backend routes | Persistence writes can fail or return stale data and must not corrupt runtime threshold state. |
| table toggle state -> D3 overlay renderer | Bad state transitions can leak thresholds into multi-tag charts or auto-enable unexpectedly. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08.1-10 | T | custom-alarm modal payload | mitigate | Validate numeric inputs client-side before API call and reject invalid values with inline error state. |
| T-08.1-11 | D | threshold overlay state machine | mitigate | Centralize single-tag guardrail checks in chart-card before invoking D3 overlay rendering. |
| T-08.1-12 | R | custom alarm edits | mitigate | After every successful save/update, refetch or reconcile current values from backend response and update visible audit metadata path. |
</threat_model>
