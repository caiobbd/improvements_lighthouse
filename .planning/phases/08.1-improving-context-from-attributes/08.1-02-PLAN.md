| client -> custom alarm routes | Untrusted numeric inputs and attribute IDs enter persistence layer. |
| API layer -> SQLite file | Write/read operations can race or fail under concurrent edits. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08.1-04 | T | `custom_alarms_store.py` SQL writes | mitigate | Use parameterized SQL (`?`) for all values and reject malformed numeric payloads in route validation. |
| T-08.1-05 | D | `custom_alarm_versions` growth | mitigate | Enforce per-attribute prune in same transaction after each update (`max 20`). |
| T-08.1-06 | R | audit trail integrity | mitigate | Persist `created_date`, `updated_date`, `version_n`, and snapshot payload on every write with deterministic incrementing. |
</threat_model>
