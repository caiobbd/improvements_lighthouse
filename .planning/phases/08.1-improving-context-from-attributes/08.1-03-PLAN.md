| global picker state -> localStorage | Persisted user runtime preferences can be malformed or stale. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-08.1-08 | D | table layout/sticky behavior | mitigate | Constrain row count to current chart tags and keep scroll confined to table container to avoid page-level repaint churn. |
| T-08.1-09 | T | localStorage column state | mitigate | Validate stored column IDs against manifest and fallback to repo defaults when invalid. |
</threat_model>
